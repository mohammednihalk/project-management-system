# 🚀 Project Management System

A modern **Django-based Project Management System** designed to help individuals and teams organize, track, and manage projects efficiently.

This web application allows users to create projects, monitor daily progress, manage deadlines, receive notifications, schedule meetings through an interactive calendar, and visualize project status from a centralized dashboard.

> **Project Status:** 🚧 Currently Under Active Development

---

# 📖 Overview

Managing multiple projects manually can be difficult and time-consuming.

The **Project Management System** was developed to simplify project tracking by providing an easy-to-use interface where users can:

- Create and manage projects
- Track project progress
- Monitor deadlines
- Schedule meetings and events
- Receive project notifications
- View project statistics
- Manage personal profile

The project is continuously being improved based on user feedback, and additional features will be added in future versions.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/mohammednihalk/project-management-system.git
```

Move into project

```bash
cd project-management-system
```

Create virtual environment

```bash
python -m venv venv
```

Activate environment

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Configure PostgreSQL database inside

```
PM_project/settings.py
```

Run migrations

```bash
python manage.py migrate
```

Start server

```bash
python manage.py runserver
```

Open

```
http://127.0.0.1:8000/
```
